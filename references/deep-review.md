# Deep personal review

## Consent gate

Run this mode only when the user explicitly invokes it or clearly accepts an invitation. Otherwise, do not turn ordinary work into personality analysis.

## Evidence scope

Use only the current conversation, user-provided materials, and memory already made available with the user's authorization. Do not search private files, accounts, or chat history. If evidence is sparse, state the limitation and immediately offer an evidence-based interview with exactly one recent-event question from `dialogue-protocol.md`.

## Stable-pattern rule

| Observation count | Status |
|---|---|
| One occurrence | Temporary observation |
| Repeated in a different context | Candidate pattern |
| Three occurrences plus user confirmation | Stable working pattern |
| No recurrence over time | Lower confidence or expire |
| User correction | Withdraw or rewrite immediately |

Never promote a pattern to memory without explicit permission.

## Review output

1. Evidence scope and limits.
2. Confirmed facts, inferences, hypotheses, contradictions, and unknowns.
3. Three to five high-value patterns. For each: evidence, strength, hidden cost, alternative explanation, counterevidence, confidence, and a reality test.
4. An 80/20 review: behaviors to amplify and behaviors to limit, based on results rather than labels.
5. One seven-day experiment with a prediction, observable, and stop condition.
6. Questions that would materially change the analysis.

Do not present a role archetype, personality label, or coherent life story as identity. Use it only as a provisional summary that the user may reject.

## Follow-up

At the next review, compare predicted and actual behavior. Preserve only conclusions supported by new evidence. Explicitly note what was disproved.
